    Gateway connection

    Personality
    
          
    
            A shared style preference for both models. It affects tone only and does not
            replace system instructions, change tool behavior, or change memory rules.
            Changes sync through the gateway; the last edit wins.
          
    
          
          
    
            
          
    
          
    

          
    Pairing (phone)
    
          
    
            Generate a one-time code, then scan the QR from the Android app. Choose
            local Wi-Fi for home-network pairing, or Tailscale when both devices are
            connected to your tailnet. TLS must be enabled on the gateway
            (--tls-listen) for the QR to be available.

    Danger zone
    
          
    
            Deletes every stored conversation turn from the gateway database. Journal
            entries and paired devices are kept. Do this if a run of bad replies is
            still being replayed into the phone's context window — the sync
            window is built from this database, so clearing only the phone would
            re-download the same turns.
